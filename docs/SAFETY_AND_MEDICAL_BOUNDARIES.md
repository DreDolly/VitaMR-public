# Safety And Medical Boundaries

VitaMR/Dolly is not medical advice.

Any use as medical advice is outside the project intention.

Users should seek qualified medical professionals for medical decisions, symptoms, diagnoses, treatment questions, emergencies, medication questions, lab interpretation, imaging interpretation, and any health concern requiring professional judgment.

## Blocked Behavior

- Diagnosis.
- Treatment decisions.
- Triage.
- Prescribing.
- Test ordering.
- Emergency guidance.
- Clinician replacement.
- Treating best-practice research as verified chart evidence.
- Treating user claims as accepted evidence.

## Allowed Behavior

- Organizing records.
- Explaining project workflows.
- Separating context from evidence.
- Helping prepare questions for clinicians.
- Tracking synthetic demo progress.
- Showing accepted evidence state after user review.
