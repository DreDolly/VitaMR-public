# Features And Workflows

## Data Hunter Basic

Data Hunter Basic asks bounded questions to help map user-provided context. Basic answers are not verified evidence.

## Master Hunt

Master Hunt turns useful clues into evidence targets. Evidence progress requires accepted vault evidence.

## Records Mode

Records Mode keeps Dolly focused on medical-record storage, retrieval, organization, and chart Q&A boundaries.

## Healthspan Mode

Healthspan Mode is opt-in. It is intended for future healthspan support and must remain separate from verified chart extraction and medical advice.

## Phone Companion

The phone companion can show chart packets, Data Hunter state, phone inbox items, and pending context. It is not the chart authority.

## Accepted Evidence

Accepted evidence comes from reviewed/accepted records or data entering the vault. A clue or claim alone does not create evidence points.
