# Roadmap

## Current Stage

VitaMR/Dolly is an active WPF prototype with an Android companion app. The current focus is source-protected record organization, Data Hunter, Master Hunt, and safe synthetic rebuild.

## Near Term

- Public-safe README and rebuild docs.
- Synthetic Bruce Wayne demo path.
- GitHub readiness audit.
- Cleaner configuration examples.
- Laptop rebuild test protocol.
- Dolly Agent Knowledge Pack scaffold.

## Later

- Runtime loading of project knowledge from the Agent Knowledge Pack.
- Stronger synthetic demo flows.
- Safer local model/OCR setup docs.
- Expanded Master Hunt evidence acceptance polish.
- Healthspan Mode planning with strict medical boundaries.

## Out Of Scope For Pilot

- Real EMR access.
- Real medical automation.
- Diagnosis, treatment, triage, prescribing, test ordering, emergency guidance, or clinician replacement.
