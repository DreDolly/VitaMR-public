# Bruce Wayne Blank Synthetic Test Patient

This folder is reserved for a blank public-safe synthetic test patient.

Bruce Wayne is not a real patient in this project. For public release, this patient should start with zero preloaded medical data.

Recommended use:

1. Start with this blank synthetic patient.
2. Add fake records or fake Data Hunter answers yourself.
3. Watch how VitaMR/Dolly separates user-provided context from accepted evidence.
4. Delete and recreate the fake data as needed.

Do not place real medical records, uploaded photos, screenshots, portal exports, lab reports, imaging reports, medication records, or PHI in this folder.
